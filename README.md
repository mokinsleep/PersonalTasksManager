一个简洁的个人任务管理工具，数据保存在浏览器本地，无多人协同功能。有优先级设置；人物简介和任务进展的填写功能，以及以这些标签为标准的多维度排序功能

一个个人任务管理工具，采用飞书任务卡片的视觉风格。主要功能包括：

三列看板（进行中/待处理/已完成），支持拖拽移动任务

每个任务支持标题、描述、截止日期、优先级（高/中/低标签）、自定义标签

任务卡片支持双击编辑、右键菜单（复制/移动/删除）、批量删除

进展记录功能：支持对每个任务添加多条历史进展，可在编辑界面查看/编辑

筛选与排序：按优先级、标签、截止日期筛选，按创建时间/截止日期/优先级排序

数据持久化：localStorage 本地存储，刷新不丢失

技术栈：原生 HTML/CSS/JS，无框架。我使用 Cline + DeepSeek-V4-Pro 作为 AI 编程助手完成开发，代码量约 2000 行。

没有多人协同功能，没有多设备同步功能，是一个非常轻便的个人工具
